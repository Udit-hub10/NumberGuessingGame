# Number Guessing Game

A simple Python number guessing game with a full-screen Tkinter UI.

## Files

- `number.py` - original console version
- `number_ui.py` - improved graphical version

## Run the UI

Open PowerShell in the project folder and run:

```powershell
cd "E:\NumberGame"
& "C:\Users\uditk\AppData\Local\Python\pythoncore-3.14-64\python.exe" ".\number_ui.py"
```

## How to play

1. Enter a number between 1 and 100.
2. The game tells you if your guess is too high or too low.
3. Keep guessing until you find the secret number.
4. Try to win in as few attempts as possible.

## Requirements

- Python 3 installed on your system
- Tkinter support (included with most Python installs)
